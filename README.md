## Brainrot Bandits – Roblox-Tycoon

Collect-and-Steal-Tycoon im Brainrot-Stil: Figuren vom Förderband kaufen, passiv Cash verdienen, bei anderen stehlen, Basis abschließen, Rebirth.

### Schnellstart (ca. 30 Minuten)
1. Studio: neues Baseplate-Spiel, veröffentlichen, API Services an → [Phase 2](docs/02_Studio-Setup.md)
2. `src/ServerStorage/SetupWorld.lua` als ModuleScript anlegen und über die Command Bar ausführen
3. Alle Scripts aus `src/` einfügen → [Phase 3](docs/03_Scripts-Installation.md)
4. Game Passes und Developer Products anlegen, IDs in `Config` eintragen → [Phase 4](docs/04_Monetarisierung.md)
5. Icon und Thumbnails aus `marketing/` hochladen, Beschreibung einfügen → [Phase 6](docs/06_Launch.md)
